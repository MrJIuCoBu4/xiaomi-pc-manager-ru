# Необязательное исправление предупреждения камеры

Подавляет только предупреждение `请确认摄像头状态` для ошибки `kLOCAL_CAMERA_DISABLED`.
Не отключает камеру, драйверы или службы и не заменяет проверку исправности самой камеры.

```powershell
.\Patch.ps1 -Action Install -CameraFix -RestartOSD
```

Меняется `PcControlCenter.dll`: операнд switch по смещению `0x2E373`
`40 00 00 00` → `D8 01 00 00` (два изменённых байта). Ветка обработчика
`SynergyUIService.ICameraCooperationWrapperUI.ExceptionCallback` направляется на существующий `ret`.

Исходный SHA256: `07CF478B75AD5045A61E27DA47DBDEFB11E45AEC2B67BD6D33458772B84ADBCD`.
Конечный SHA256: `E7004E2B57B37014EB60C274CDA07F70F6CB1664E1D6EF396F46E2C5A56472C9`.

**После изменения цифровая подпись DLL не соответствует содержимому.** Защита Windows не обходится.
По умолчанию эта опция выключена. Restore отменяет её только если DLL менял именно этот установщик;
ранее установленное исправление камеры сохраняется.
