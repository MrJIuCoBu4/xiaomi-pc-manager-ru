# Changelog

## 1.4.5-rc.1

Добавлены пропущенные подписи «常用软件专清» → «Приложения» и «Microsoft Office缓存» → «Кэш Microsoft Office».
Словарь отображения содержит 18 записей. Остальная структура JavaScript и логика очистки не изменены.

## 1.4.4-rc.1

Переведены 16 известных названий категорий и приложений на странице очистки, включая временные файлы,
журналы, корзину и браузеры. Словарь применяется только в двух местах отображения: идентификаторы,
исходные данные, выбор файлов и команды удаления не меняются. Неизвестные названия сохраняются.
Кнопка сокращена до «Очистить», добавлены внутренние отступы и запрет переноса. Сокращён заголовок результата.
Установщик поддерживает малые дополнительные дельта-архивы; обновление сохраняет первоначальные резервные копии.

## 1.4.3-rc.1

Первый накопительный кандидат для публичного распространения, Xiaomi 5.8.1.130.
Основан на локальных RU v1–v1.4.3: перевод ресурсов, адаптация интерфейса, отступы, 748 изображений OSD.
Опциональный узкий патч предупреждения камеры. Новый установщик с SHA256, локальными резервными копиями,
журналом прерываний и восстановлением. Полные файлы Xiaomi в комплект не входят.
Изменения EXE входа Xiaomi исключены. Непереведённые окна перечислены в docs/KNOWN_ISSUES.md.
