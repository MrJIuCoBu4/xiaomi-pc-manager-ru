# Changelog

## 1.4.3-rc.1

Первый накопительный кандидат для публичного распространения, Xiaomi 5.8.1.130.
Основан на локальных RU v1–v1.4.3: перевод ресурсов, адаптация интерфейса, отступы, 748 изображений OSD.
Опциональный узкий патч предупреждения камеры. Новый установщик с SHA256, локальными резервными копиями,
журналом прерываний и восстановлением. Полные файлы Xiaomi в комплект не входят.
Изменения EXE входа Xiaomi исключены. Непереведённые окна перечислены в docs/KNOWN_ISSUES.md.
