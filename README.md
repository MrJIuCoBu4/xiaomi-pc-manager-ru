# Русификатор Xiaomi PC Manager

**Версия патча: 1.5.** Для **Xiaomi PC Manager 5.8.1.130**, Windows 11.

Переведены основные страницы и экранные уведомления, исправлены подписи и размеры элементов.
Камера, синхронизация и автозапуск сохраняются. Некоторые нативные окна ещё не переведены.

## Скачать и установить

1. **[Скачать ZIP](https://github.com/MrJIuCoBu4/xiaomi-pc-manager-ru/archive/refs/heads/main.zip)** и распаковать целиком.
2. Закрыть Xiaomi PC Manager через «Выход» в трее.
3. Открыть PowerShell **от администратора** в распакованной папке и выполнить:

```powershell
.\Patch.ps1 -Action Install -RestartOSD
```

Затем запустить Xiaomi PC Manager обычным способом.

**Python, Node.js и сторонние библиотеки не нужны.** Используются PowerShell и встроенные средства Windows.
Установщик не отключает защиту Windows и не меняет политику запуска скриптов.

## Откат

Закройте приложение и выполните от администратора:

```powershell
.\Patch.ps1 -Action Restore -RestartOSD
```

Возвращается состояние до установки. Не удаляйте папку `.xiaomi-pc-manager-ru` внутри каталога Xiaomi:
в ней резервные копии. При прерванной установке — [восстановление](RECOVERY.md).

## Дополнительно

- Проверка без изменений: `.\Patch.ps1 -Action Status`.
- Другой каталог: добавьте `-TargetPath 'D:\Apps\XiaomiPCManager\5.8.1.130'`.
- Без перевода OSD: добавьте `-NoOSD` к установке.
- Исправление предупреждения камеры: [отдельная добровольная опция](CAMERA.md).

Файлы проверяются по SHA256. Неизвестная сборка или сторонние изменения блокируют установку.
Полные файлы программы Xiaomi в репозитории не распространяются; дельты применяются к вашей установленной копии.

Пока не исправлены: заголовок окна входа, отступ кнопки Google, нативная подсказка в трее
и отдельное предупреждение о неотвечающем Проводнике. В узком окне возможна вертикальная прокрутка.

[Сообщить об ошибке](https://github.com/MrJIuCoBu4/xiaomi-pc-manager-ru/issues/new).
На скриншоте скройте серийный номер и данные аккаунта.

Проект неофициальный и не связан с Xiaomi.
