# Русификатор Xiaomi PC Manager

**Версия патча: 1.6.** Для **Xiaomi PC Manager 5.8.1.130**, Windows 11.

Переведены основные страницы и экранные уведомления, исправлены подписи и размеры элементов.
Камера, синхронизация и автозапуск сохраняются. Некоторые нативные окна и редкие названия из каталога сторонних программ ещё не переведены.

В 1.6 исправлена вёрстка всего раздела характеристик: названия, модели оборудования, интервалы,
переносы и кнопка переименования. Расширен перевод автозагрузки и подсказок поиска устройств.

## Скачать и установить

1. **[Скачать ZIP](https://github.com/MrJIuCoBu4/xiaomi-pc-manager-ru/archive/refs/heads/main.zip)** и распаковать целиком. Не запускайте файлы прямо из ZIP.
2. Открыть распакованную папку: в ней должны быть `Patch.ps1` и папка `patches`. При распаковке может получиться две вложенные папки с одинаковым названием — нужна внутренняя.
3. Закрыть Xiaomi PC Manager через «Выход» в трее.
4. Нажать «Пуск», найти **PowerShell**, нажать правой кнопкой → **Запуск от имени администратора**. Подтвердить запрос Windows.
5. В Проводнике скопировать путь к папке с `Patch.ps1` из адресной строки. В PowerShell перейти в неё, подставив этот путь вместо примера:

```powershell
cd 'C:\Users\Имя\Downloads\xiaomi-pc-manager-ru-main\xiaomi-pc-manager-ru-main'
```

6. Если доверяете скачанному коду этого проекта, снять интернет-блокировку **только с файла установщика**, затем запустить установку:

```powershell
Unblock-File -LiteralPath .\Patch.ps1
.\Patch.ps1 -Action Install -RestartOSD
```

После успешного завершения запустить Xiaomi PC Manager обычным способом. Двойной щелчок по `Patch.ps1` не заменяет эти действия.

**Python, Node.js и сторонние библиотеки не нужны.** Используются PowerShell и встроенные средства Windows.

### Ошибка «файл не содержит цифровой подписи»

`Patch.ps1` не подписан сертификатом издателя. Windows может пометить скачанный ZIP и распакованные скрипты как полученные из интернета. При политике **RemoteSigned** такой неподписанный скрипт не запускается, пока пользователь явно не разблокирует его.

Команда `Unblock-File -LiteralPath .\Patch.ps1` выше снимает эту метку с указанного файла. Она **не подписывает код, не проверяет его безопасность и не меняет политику PowerShell**. Выполняйте её только для копии, полученной из этого репозитория и которой вы доверяете. Не разблокируйте рекурсивно всю папку «Загрузки».

Вариант через Проводник: правой кнопкой по `Patch.ps1` → **Свойства** → **Разблокировать** (если этот пункт есть) → **Применить**. После этого повторить команду установки.

Если ошибка остаётся, выполните в том же окне PowerShell:

```powershell
Get-ExecutionPolicy
Get-ExecutionPolicy -List
```

- **RemoteSigned**: проверьте, что разблокирован именно тот `Patch.ps1`, который запускаете, и что текущая папка правильная.
- **AllSigned**: требуется доверенная цифровая подпись; разблокировка не поможет.
- **Restricted**: запуск скриптов запрещён; разблокировка не поможет.
- Политики в **MachinePolicy** или **UserPolicy** задаёт администратор организации. Для установки обратитесь к нему; установщик эти ограничения не меняет.

Не используйте для решения этой ошибки `Bypass`, `Unrestricted` и отключение защиты Windows. При `RemoteSigned` для показанной ошибки достаточно точечной разблокировки доверенного файла. При другой политике сначала уточните ограничения у администратора.

Подробнее: [документация Microsoft о политиках PowerShell](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies/).

## Откат

Закройте приложение и выполните от администратора:

```powershell
.\Patch.ps1 -Action Restore -RestartOSD
```

Возвращается состояние до установки. Не удаляйте папку `.xiaomi-pc-manager-ru` внутри каталога Xiaomi:
в ней резервные копии. При прерванной установке — [восстановление](RECOVERY.md).

## Дополнительно

- Проверка без изменений: `.\Patch.ps1 -Action Status`.
- Другой каталог: добавьте `-TargetPath 'D:\Apps\XiaomiPCManager\5.8.1.130'`.
- Без перевода OSD: добавьте `-NoOSD` к установке.
- Исправление предупреждения камеры: [отдельная добровольная опция](CAMERA.md).

Файлы проверяются по SHA256. Неизвестная сборка или сторонние изменения блокируют установку.
Полные файлы программы Xiaomi в репозитории не распространяются; дельты применяются к вашей установленной копии.

Пока не исправлены: заголовок окна входа, отступ кнопки Google, нативная подсказка в трее
и отдельное предупреждение о неотвечающем Проводнике. В узком окне возможна вертикальная прокрутка.

[Сообщить об ошибке](https://github.com/MrJIuCoBu4/xiaomi-pc-manager-ru/issues/new).
На скриншоте скройте серийный номер и данные аккаунта.
