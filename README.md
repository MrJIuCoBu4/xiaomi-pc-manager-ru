# Xiaomi PC Manager RU

Неофициальная русификация **Xiaomi PC Manager 5.8.1.130** для Windows 11.
Текущий публичный кандидат: **1.4.5-rc.1**. Это накопительный патч: устанавливать предыдущие RU-пакеты не нужно.

## Что меняется

- Перевод ресурсов PRI и веб-интерфейса; компактные подписи и адаптация карточек, кнопок и справки.
- Видимые отступы между жирными подписями и значениями характеристик.
- Перевод категорий очистки при отображении, краткая кнопка «Очистить» без переноса.
- Русские подписи в 748 изображениях экранных уведомлений OSD: обе темы и все исходные масштабы.
- Опционально: подавление ошибочного уведомления `请确认摄像头状态` при запуске.

Камера, синхронизация устройств, службы и автозапуск не отключаются. Установщик не меняет реестр,
не перезагружает Windows, не скачивает DLL и не отключает защитные механизмы Windows.

**Перевод пока неполный.** [Известные ограничения](docs/KNOWN_ISSUES.md): окно входа Xiaomi,
кнопка Google, нативная подсказка в трее и отдельное предупреждение о Проводнике.

## Требования

- Установленный Xiaomi PC Manager **5.8.1.130**, Windows 11, Python **3.10+**.
- Администратор для установки/отката; для проверки состояния права администратора не нужны.
- Поддерживаемые исходные хеши перечислены в `patches/catalog.json`.
  Название версии само по себе недостаточно: неизвестные сборки и сторонние изменения блокируются.

Репозиторий и релиз содержат скрипты, переводы и данные дельта-патчей. Полные DLL/EXE, полные JS/CSS/PRI,
установщик Xiaomi и личные резервные копии не распространяются. Дельта-данные могут содержать фрагменты
исходных ресурсов; они требуют собственных файлов поддерживаемой установленной версии.

## Установка

1. Скачайте ZIP релиза из [Releases](https://github.com/MrJIuCoBu4/xiaomi-pc-manager-ru/releases) и **распакуйте полностью**.
   Альтернатива: Code → Download ZIP; скрипты должны лежать рядом с папками `src` и `patches`.
2. Закройте Xiaomi PC Manager через пункт **«Выход»** в трее.
3. Откройте PowerShell в распакованной папке. Сначала проверьте состояние:

```powershell
.\Patch.ps1 -Action Status
```

4. Откройте PowerShell **от администратора** и установите перевод:

```powershell
.\Patch.ps1 -Action Install -RestartOSD
```

`-RestartOSD` разрешает перезапуск только `OSDUtility.exe` из проверенного каталога приложения, если он работает.
Камера и другие службы не останавливаются. После установки запустите Xiaomi PC Manager обычным способом.

Если политика PowerShell запрещает запуск скриптов, **не отключайте её**. Можно вызвать Python напрямую
из той же папки (для установки — также из консоли администратора):

```powershell
py -3 patch.py status
py -3 patch.py install --restart-osd
```

Нестандартный каталог: `-TargetPath 'D:\Apps\XiaomiPCManager\5.8.1.130'`
(для Python: `--target 'D:\Apps\XiaomiPCManager\5.8.1.130'`).
Только основной интерфейс, без OSD: добавьте `-NoOSD` / `--no-osd`.

## Исправление предупреждения камеры — отдельно и добровольно

```powershell
.\Patch.ps1 -Action Install -CameraFix -RestartOSD
# или
py -3 patch.py install --camera-fix --restart-osd
```

Эта опция меняет два байта в `PcControlCenter.dll`: только ветвь `kLOCAL_CAMERA_DISABLED` в обработчике
исключения камеры направляется на существующий `ret`. Другие ошибки камеры не подавляются.
Проверка конкретной камеры этим исправлением не заменяется.

**Подпись Authenticode у изменённой DLL перестаёт соответствовать файлу.** Проверки Windows не обходятся.
По умолчанию DLL не изменяется; если исправление уже установлено, обычная русификация сохраняет его.
[Техническое описание](docs/CAMERA.md).

## Откат

Закройте приложение, затем выполните от администратора:

```powershell
.\Patch.ps1 -Action Restore -RestartOSD
# или
py -3 patch.py restore --restart-osd
```

Откат возвращает **состояние перед первой установкой этого общественного пакета**, только для файлов,
которые он менял. Например, ранее установленное исправление камеры сохранится, если этот пакет его не записывал.
Резервные копии находятся в `.xiaomi-pc-manager-ru` внутри каталога приложения. Не удаляйте их до отката.
Не смешивайте команды отката из прежних экспериментальных пакетов с новым установщиком.

При сбое питания или прерванной операции: [восстановление](docs/RECOVERY.md).
После обновления Xiaomi не переносите старые патчи на новую сборку: новые хеши требуют отдельного анализа.

## Проверки и ограничения релиза

- 754 файла в каталоге: 753 для UI/OSD и одна необязательная DLL камеры.
- Все дельты проверены восстановлением точного конечного файла и сравнением SHA256 при сборке.
- Есть тесты повторной установки, отката, отказа на неизвестных файлах, повреждённого пакета,
  частичной записи, прерывания и небезопасных путей.
- Публичный установщик проверяется на тестовых копиях; тестирование на разных моделях ноутбуков ещё нужно.
- SHA256 защищает от случайного повреждения и несовместимости; он не заменяет доверие к источнику скачивания.
