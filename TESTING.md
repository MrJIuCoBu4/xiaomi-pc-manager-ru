# Проверки 1.5

Установщик не требует Python, Node.js, npm или сторонних модулей PowerShell.
Дельты и конечные хеши совпадают с последней проверенной русификацией; в словаре очистки 18 записей,
включая «Приложения» и «Кэш Microsoft Office».

Тесты PowerShell в `tests/Test-Patch.ps1` проверяют установку, повторный запуск, откат,
добровольное изменение камеры, сохранение ранее установленного исправления, отказ на неизвестном хеше,
откат после частичной записи, восстановление по журналу и ограничения путей/дельт.

```powershell
.\tests\Test-Patch.ps1
```

Проверка в этой рабочей среде выполнена на PowerShell 7. Синтаксис проверяется также парсером Windows PowerShell 5.1.
Запуск скриптов в Windows PowerShell 5.1 на этой машине запрещён политикой; она не изменялась и не обходилась.
Проверка на всех моделях ноутбуков, темах и масштабах не заявляется.

На изолированной копии 754 реальных файлов выполнены установка через новый PowerShell-движок,
проверка всех конечных SHA256, повторная установка без изменений и откат с проверкой всех 754 исходных SHA256.
Финальный каталог 1.5 и переименованный дополнительный архив отдельно проверены установкой и откатом UI.
Рабочая установка Xiaomi при этих тестах не изменялась.
