# Исправление предупреждения камеры

Сборка: Xiaomi PC Manager 5.8.1.130, managed `PcControlCenter.dll`, размер 1 359 064 байт.

- Исходный SHA256: `07CF478B75AD5045A61E27DA47DBDEFB11E45AEC2B67BD6D33458772B84ADBCD`.
- Конечный SHA256: `E7004E2B57B37014EB60C274CDA07F70F6CB1664E1D6EF396F46E2C5A56472C9`.
- Метод: явная реализация `MiSmartShareClrWrapper.ICameraCooperationWrapperUI.ExceptionCallback`
  в `PcControlCenter.Services.UI.MainView.Instances.SynergyUIService`.
- Исследованная ветвь: `CameraExceptionId.kLOCAL_CAMERA_DISABLED` (case 3).
- RVA метода: `0x300DC`; начало IL в файле: `0x2E2E8`.
- Операнд элемента switch по смещению файла `0x2E373`: `40 00 00 00` → `D8 01 00 00`.
- Переход `IL_0117` заменён на существующий `IL_02AF` (`ret`). Два изменённых байта, размер DLL сохранён.

Это подавляет показ конкретного предупреждения `请确认摄像头状态`. Другие ветви обработчика,
драйверы, разрешения Windows, включение камеры и службы не меняются.
Причина ложной диагностики на всех моделях ноутбуков не установлена; патч не ремонтирует камеру.

Полная DLL в репозиторий не включена; дельта применяется только к известному исходному хешу.
Изменение нарушает соответствие Authenticode-подписи содержимому DLL. Опция выключена по умолчанию.
Откат восстанавливает локальную резервную копию только если именно этот установщик менял DLL.
