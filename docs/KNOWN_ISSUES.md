# Известные ограничения

- Только Xiaomi PC Manager 5.8.1.130 с известными SHA256. Другие версии не поддерживаются автоматически.
- Перевод не является полным: некоторые нативные окна и серверные страницы остаются китайскими.
- Заголовок окна входа `账号登录` не меняется. Для согласованного перевода нужны изменения в
  `MiUserLogon.exe` и `MiAccountBroker.exe` из MiService; в этот релиз они не включены.
- Отступ между логотипом Google и текстом на серверной странице входа пока не исправлен.
- Нативная подсказка значка в трее и отдельное предупреждение о неотвечающем Проводнике не переведены.
- При узком/низком окне может появиться вертикальная прокрутка. Работа на всех DPI ещё не подтверждена.
- Исправление камеры подавляет конкретное уведомление, но не доказывает работоспособность камеры.
- Старые экспериментальные пакеты не имеют журнала нового установщика. Новый Restore не отменяет
  изменения, которые были сделаны до него и не были им перезаписаны.
- Если другой процесс удерживает ресурс, запись может завершиться ошибкой; сделанные этим запуском
  изменения откатываются. Не отключайте антивирус и не обходите защитные проверки ради установки.
