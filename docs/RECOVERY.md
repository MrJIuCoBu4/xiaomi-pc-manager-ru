# Восстановление

Установщик хранит резервные копии, состояние и журнал в `<каталог Xiaomi>/.xiaomi-pc-manager-ru`.
Никакой откат не скачивается из сети.

1. Закройте Xiaomi PC Manager. Убедитесь, что предыдущий процесс установки уже завершён.
2. Выполните `py -3 patch.py status` в папке релиза.
3. Если есть `transaction.lock` после аварийного завершения, сначала убедитесь, что **ни один установщик не работает**.
   Только после этого удалите **этот один файл** `transaction.lock` из `.xiaomi-pc-manager-ru` вручную.
   Не удаляйте папку, `backups`, `state.json` или `pending.json`.
4. Если есть `pending.json`, выполните из консоли администратора:

```powershell
py -3 patch.py recover --restart-osd
```

Recover возвращает файлы к состоянию до прерванной операции. Затем можно повторить установку или откат.
Каждая резервная копия проверяется по SHA256. Если файл изменён обновлением Xiaomi или другим патчем,
восстановление откажется его перезаписывать. Сохраните каталог резервных копий и создайте Issue,
приложив текст ошибки и версию — без самих бинарников и личных данных.

Если резервные копии потеряны, этот проект не может восстановить неизвестную сборку из сети.
Используйте исходный установщик Xiaomi нужной версии. Не скачивайте отдельные DLL с посторонних сайтов.

Restore возвращает файлы перед первой установкой этого пакета; это не обязательно китайский интерфейс.
После успешного отката резервные копии остаются для ручной проверки, но список активных изменений очищается.
