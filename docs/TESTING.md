# Локальная проверка 1.4.3-rc.1

Дата: 2026-10-26. Промежуточные локальные пакеты исследовались на Xiaomi PC Manager 5.8.1.130.
Этот публичный кандидат не выдаётся за проверенный на всех ноутбуках или DPI.

- 767 дельт для 754 файлов восстановлены из известных локальных исходников с точным совпадением SHA256.
- 13 автоматических тестов движка: успешная и повторная установка, добровольный патч камеры,
  сохранение ранее установленного исправления, откат, повреждённый пакет/backup, неизвестные хеши,
  сбой после частичной записи, восстановление по журналу, отказ при посторонних изменениях,
  блокировка параллельных операций и небезопасные пути.
- На отдельной тестовой копии всех 754 реальных исходных файлов выполнены Install с камерой,
  повторный Install (0 изменений), проверка всех конечных хешей и Restore (754 исходных хеша совпали).
- Рабочая установка приложения этими проверками не изменялась.
- PowerShell-точка входа проверена синтаксическим анализатором.
- GitHub Actions добавлены в репозиторий, но их удалённый запуск нужно подтвердить после публикации.

Остаётся ручная проверка первого публичного установщика в работающем приложении на разных моделях,
обеих темах, масштабах Windows и с реально работающим OSDUtility.
